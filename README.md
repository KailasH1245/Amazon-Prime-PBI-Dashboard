# 🎬 Amazon Prime Video Dashboard — Power BI

## 📌 Overview
An interactive Power BI dashboard analyzing Amazon Prime Video's content library. This project explores content distribution across genres, ratings, countries, and release years — providing insights into the platform's catalog strategy and growth over time.

---

## 🎯 Objectives
- Analyze total titles available on Amazon Prime Video
- Break down content by Movies vs TV Shows
- Explore top genres, age ratings, and countries of origin
- Visualize content growth trends over the years

---

## 📊 Dashboard Features

| Visual | Description |
|---|---|
| 🎯 KPI Cards | Total Titles, Total Ratings, Total Genres, Total Directors |
| 🍩 Movies vs TV Shows | Donut chart showing content type split |
| 📊 Top Genres | Horizontal bar chart of most popular genres |
| 🔞 Ratings Distribution | Bar chart breakdown by age rating |
| 🗺️ Content by Country | Map visualization of global content origin |
| 📈 Release Year Trend | Area chart showing catalogue growth over time |
